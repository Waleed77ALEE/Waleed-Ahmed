# Waleed-Ahmed

Welcome to the **Waleed-Ahmed** repository! This is a modern web application built with a robust, high-performance tech stack.

## 🚀 Tech Stack

- **Frontend Build Tool:** [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Package Manager & Runtime:** [Bun](https://bun.sh/)
- **Backend/BaaS:** [Firebase](https://firebase.google.com/) & [Supabase](https://supabase.com/)
- **Deployment:** [Vercel](https://vercel.com/)

## 📂 Project Structure

- `/src` - Application source code and components.
- `/public` - Static assets.
- `/assets` - Additional project assets.
- `/supabase` - Supabase edge functions and database migrations.
- `firebase-*.json` & `firestore.rules` - Firebase configuration and security rules.
